Questions

Before you buy.

Do we need a developer?

No. An admin installs the package, assigns permission sets, and picks objects and fields on the Sojourn Settings page. Objects other than Case, Lead, and Opportunity need one record-triggered Flow, copied from the template in the package.

Does it use our data storage?

Yes. Each interval is a record in your org. In release 1, a daily summary and an optional archive to a big object keep storage in check on very large orgs.

Which editions are supported?

Enterprise, Unlimited, Performance, and Developer Edition. Omni-Channel attribution needs the Sojourn Omni-Channel extension and Omni-Channel enabled.

What happens to our data if we uninstall?

Export your intervals first with the purge export or any report. Uninstalling a managed package removes its objects and their records.

When will Sojourn be on AppExchange?

After Salesforce's AppExchange security review. The package goes to review in sprint 8 of release 1, and the listing follows when it clears.

Can we install it in production?

Early-access customers install by package version ID, into a sandbox first.

Who reads our request?

Sandeep and Vikash, the two people building Sojourn. One of them replies in writing within one working day.

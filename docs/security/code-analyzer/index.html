    Code Analyzer results

    What Salesforce Code Analyzer reports on the Sojourn package, and every finding accepted with its reason.

    The Code Analyzer workflow scans the package directories sojourn/ and sojourn-omni/ on every pull request, every push to main, and every week. It runs the AppExchange and Recommended rule selectors, which include every rule in the command the AppExchange security review prescribes, and Salesforce Graph Engine, which follows data from each entry point through the Apex classes to find missing access checks. This page is generated from those scans, and the workflow fails when the page and the scans disagree.

    Engines: code-analyzer 0.53.0, cpd 0.46.0, pmd 0.46.0, regex 0.40.0, sfge 0.25.0.

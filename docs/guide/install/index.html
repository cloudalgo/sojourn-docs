    Guide

    Install Sojourn

    Install the package in a sandbox or production org and open the Sojourn app.

    Salesforce admin About 10 minutes Since release 1

    Before you install#

    • Salesforce Enterprise, Unlimited, Performance, or Developer Edition.
    • Business hours defined in Setup, under Business Hours. Sojourn uses the org default unless you set others.

    Install#

    Release 1 is in development, so there is no AppExchange listing yet. Early access customers receive a package version ID from CloudAlgo. Request a package version ID.

    1. Install the package version, using the ID you were given:

      sf package install --package 04t... --target-org my-sandbox --wait 20

    2. Assign permission sets, as described in Assign permission sets.

    3. Open the Sojourn app from the App Launcher.

    You are done when

    • The Sojourn app appears in the App Launcher.
    • The app opens with an Intervals tab in its navigation.

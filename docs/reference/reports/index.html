    Reports and dashboards

    Every report and dashboard that installs with Sojourn, with the filters each relies on.

    The reports install in the Sojourn Reports folder and the dashboards in Sojourn Dashboards, both read only, so copy one to change it. The Omni-Channel report installs with the Sojourn Omni-Channel package. How to read and adapt them: Report cookbook.

    Reports#

    Report Report type What it shows
    Average Hours per Owner, 30 Days Sojourn Intervals Average business hours a Case stayed with each owner, for stays entered in the last 30 days. Filters: Parent Object equals Case, Tracked Field equals OwnerId, Exited At not blank.
    Average Hours per Status, 90 Days Sojourn Intervals Average business hours of a finished Case stay in each status, entered in the last 90 days. Filters: Parent Object equals Case, Tracked Field equals Status, Exited At not blank.
    Average Hours per Status by Week Sojourn Interval Summaries Weekly average business hours per Case status, from the daily summaries, so it stays fast at any volume. Filters: Granularity equals Day, Parent Object equals Case, Tracked Field equals Status.
    Error Log by Type Sojourn Error Logs Error Log entries by type and status: what Sojourn could not record, and whether it was fixed. No filters.
    First Close Time by Agent Cases Average business minutes to a Case's first close, by its current owner. Filters: Sojourn First Closed At not blank. Uses the Case metrics.
    Lead Time in Status Leads with Sojourn Intervals Average and total business hours Leads spent in each status. Filters: Tracked Field equals Status.
    Lead Time per Owner Leads with Sojourn Intervals Average and total business hours Leads spent with each owner. Filters: Tracked Field equals OwnerId.
    Longest Open Intervals Sojourn Intervals The 25 open stays with the most business minutes so far, on any object and field. Filters: Is Open. Minutes to date need the Live values job.
    Open Cases by Status and Time to Date Sojourn Intervals Cases in each status right now, with business minutes so far. Filters: Is Open, Parent Object equals Case, Tracked Field equals Status. Minutes to date need the Live values job.
    Opportunity Time in Stage Opportunities with Sojourn Intervals Average and total business hours Opportunities spent in each stage. Filters: Tracked Field equals StageName.
    Opportunity Time per Owner Opportunities with Sojourn Intervals Average and total business hours Opportunities spent with each owner. Filters: Tracked Field equals OwnerId.
    Owner Changes per Case Cases Handoffs between owners on each Case (Sojourn Owner Change Count), grouped by the current owner. Uses the Case metrics; no filters.
    Owner Leaderboard, Last 30 Days Sojourn Interval Summaries Stays each user owner finished in the last 30 days, from the daily summaries. Filters: Granularity equals Day, Tracked Field equals OwnerId, Owner Type equals User.
    Reopened Cases by Agent Cases Cases reopened at least once, and how often, by current owner. Filters: Sojourn Reopen Count greater than 0. Uses the Case metrics.
    SLA Breaches by Status and Owner Sojourn Intervals Stays that went past their goal, by value and owner, on any object. Filters: Is Breached.
    Share of Time per Status Group Sojourn Intervals Business minutes in each status group. Customer and Company hold example statuses: edit the Status group bucket to your values (see the cookbook). Filters: Parent Object equals Case, Tracked Field equals Status.
    Status Changes per Case Cases Status changes on each Case after creation (Sojourn Status Change Count), grouped by current status. Uses the Case metrics; no filters.
    Time in Status by Case Cases with Sojourn Intervals Business hours each Case spent in each status. Filters: Tracked Field equals Status.
    Time per Owner by Case Cases with Sojourn Intervals Business hours each Case spent with each owner, queues and users. Filters: Tracked Field equals OwnerId.
    Omni-Channel Agent Handle Time Sojourn Intervals Average and total business hours per agent of routed work, from Agent work Intervals. Filters: Tracked Field equals AgentWork. Needs the Sojourn Omni-Channel package.

    Dashboards#

    Desk Productivity#

    How long each owner holds a Case, how often Cases change hands, and what is open now. Runs as the installing admin.

    • Average hours per owner, 30 days: Average Hours per Owner, 30 Days
    • Owner changes per Case: Owner Changes per Case
    • Open Cases by status: Open Cases by Status and Time to Date

    Leaderboards#

    Stays each owner finished in the last 30 days and the weekly trend, from the daily summaries. Runs as the installing admin.

    • Owner leaderboard, 30 days: Owner Leaderboard, Last 30 Days
    • Average hours per status by week: Average Hours per Status by Week

    Process Bottlenecks#

    Where Cases wait: average hours per status, the longest open stays, and the weekly trend. Runs as the installing admin.

    • Average hours per status, 90 days: Average Hours per Status, 90 Days
    • Longest open stays: Longest Open Intervals
    • Average hours per status by week: Average Hours per Status by Week

    SLA Health#

    Stays past their goal by status and owner, open Cases with time so far, and the time to first close. Runs as the installing admin.

    • Breaches by status and owner: SLA Breaches by Status and Owner
    • Open Cases by status: Open Cases by Status and Time to Date
    • First close time by agent: First Close Time by Agent

    Error Log

    The Error Log object records a change Sojourn could not turn into an Interval, with the Parent Id, Tracked Field, From and To Values, Occurred At, Error Type, and Message. Health Monitor users create the missing Interval, ignore, or resolve it, and the nightly reconcile retries Limit and DML errors. Commonly used as the error queue in the Health Monitor tab.

    API name: Error_Log__c

    Field API name Type Description
    Changed By Changed_By__c Lookup (User) Who made the change that failed to record.
    Help text: Who made the change.
    Error Type Error_Type__c Picklist: DML, Limit, Config, BusinessHours, Unknown Category of failure, which decides whether reconcile retries it automatically.
    Help text: DML and Limit errors are retried by reconcile. Config and BusinessHours errors need an admin.
    From Value From_Value__c Text (255) Value before the failed change.
    Help text: Value before the change.
    Message Message__c LongTextArea (32768) Error message as captured.
    Occurred At Occurred_At__c DateTime When the change happened, used as the interval boundary on repair.
    Help text: When the change happened.
    Owner Id Owner_Id__c Text (18) Owner of the record when the change happened.
    Parent Id Parent_Id__c Text (18) Id of the tracked record the failed change belongs to.
    Help text: Id of the tracked record.
    Parent Object Parent_Object__c Text (255) API name of the tracked object.
    Repaired Interval Repaired_Interval__c Lookup (Interval__c) Interval created when the error was repaired.
    Retry Count Retry_Count__c Number (3, 0) Times reconcile retried this error; retries stop at the configured maximum.
    Help text: Times the nightly reconcile retried this error.
    Source Source__c Picklist: Trigger, Flow, Backfill-History, Backfill-Seed, Manual-Repair, Reconcile, Catch-Up, Omni-Channel Which capture path produced the error.
    Stack Stack__c LongTextArea (32768) Stack trace, truncated.
    Help text: Stack trace for support.
    Status Status__c Picklist: New, Resolved, Ignored Workflow state of the error in the repair queue.
    Help text: New errors wait for repair or retry. Resolved and Ignored errors are kept for audit.
    To Value Id To_Value_Id__c Text (18) Id behind the new value for lookup and owner changes, needed to replay the change.
    Help text: Id of the user, queue, or related record for lookup and owner changes.
    To Value To_Value__c Text (255) Value after the failed change.
    Help text: Value after the change.
    Tracked Field Tracked_Field__c Text (255) API name of the tracked field whose change failed.
    Help text: API name of the tracked field.

    Interval Summary

    The Interval Summary object consolidates closed Intervals into one row per period, Tracked object, Tracked field, value, and owner, plus all-owners rows for org-wide charts, with counts, sum, average, minimum, and maximum minutes. The nightly Summaries job builds Day and Month rows; a purge run keeps Month rows and removes Day rows older than Summary Rollup Days. Read by the Owner Leaderboard 30 Days and Average Hours per Status by Week reports, the packaged dashboards built on them, and Sojourn Dashboards.

    API name: Interval_Summary__c

    Field API name Type Description
    All Owners All_Owners__c Checkbox Checked on an all-owners row: the same period, Tracked object, Tracked field, value, value group, and Record Closed as the per-owner rows, with every owner's Intervals added together. Its key's owner part is an asterisk (), and Owner Id, Owner Name, Owner Type, and Owner User are blank. Unchecked (the default) on a per-owner row. The nightly Summaries job adds each closed Interval to its owner's rows and to the all-owners rows, so every Interval is counted twice. Sojourn Dashboards read the all-owners rows for org-wide charts and the per-owner rows for owner charts; the packaged summary reports keep All Owners false.
    Help text:* Checked when this row adds up every owner together. Each stay is counted in its owner's row and again in an all-owners row, so filter any report you build on All Owners, or its totals double.
    Avg Business Minutes Avg_Business_Minutes__c Number (16, 2) The average business minutes of the Intervals this row counts: Sum Business Minutes divided by Interval Count, to two decimal places. Business minutes count only time inside each Interval's Business hours. Recalculated by the nightly Summaries job each time it adds Intervals to the row; blank while no counted Interval has business minutes.
    Help text: Average time per stay in this row, inside Business hours. To average across several rows, divide the summed Sum Business Minutes by the summed Interval Count instead of averaging this column.
    Avg Calendar Minutes Avg_Calendar_Minutes__c Number (16, 2) The average calendar minutes of the Intervals this row counts: Sum Calendar Minutes divided by Interval Count, to two decimal places. Calendar minutes are the elapsed clock time from Entered At to Exited At, nights and weekends included. Recalculated by the nightly Summaries job each time it adds Intervals to the row; blank while no counted Interval has calendar minutes.
    Help text: Average elapsed time per stay in this row, nights and weekends included. To average across several rows, divide the summed Sum Calendar Minutes by the summed Interval Count.
    Breach Count Breach_Count__c Number (9, 0) How many of the Intervals this row counts were breached: their business minutes passed their Goal's target (the Interval's Is Breached). A whole number, 0 when none breached. Added to by the nightly Summaries job. Sojourn Dashboards add it up for breach charts and divide it by Interval Count for the breach rate.
    Help text: Stays in this row that went past their Goal's target. Divide by Interval Count for the breach rate.
    Granularity Granularity__c Picklist: Day, Month The length of the period this row covers: Day or Month. The nightly Summaries job adds each closed Interval to one Day row, for the day it ended in the org's time zone, and to one Month row for that month, so Day and Month rows count the same Intervals and are never added together. Day rows older than Summary Rollup Days (blank means 400) are deleted only at the end of a complete purge run; purge never deletes Month rows. Sojourn Dashboards and the summary reports filter on one granularity.
    Help text: Day rows count one day; Month rows count a whole month. The same stays are in both, so filter a report to one granularity. Old Day rows are removed only by a purge run; Month rows are kept.
    Interval Count Interval_Count__c Number (9, 0) How many closed Intervals this row counts, a whole number. The nightly Summaries job adds 1 for each closed Interval not yet summarised (an Interval is summarised once, which sets its Summarised At); Rebuild summaries deletes the rows of the chosen months and counts their Intervals again. Sojourn Dashboards and the summary reports add it up for counts and divide summed minutes by it for averages.
    Help text: Number of stays this row counts. Add it up across rows for totals, and divide summed minutes by it for averages.
    Max Business Minutes Max_Business_Minutes__c Number (16, 2) The longest single Interval this row counts, in business minutes (time inside its Business hours). Kept by the nightly Summaries job as it adds Intervals to the row; blank while no counted Interval has business minutes.
    Help text: The longest stay in this row, inside Business hours. Compare it with the average to spot the outliers behind it.
    Max Calendar Minutes Max_Calendar_Minutes__c Number (16, 2) The longest single Interval this row counts, in calendar minutes (elapsed clock time, nights and weekends included). Kept by the nightly Summaries job as it adds Intervals to the row; blank while no counted Interval has calendar minutes.
    Help text: The longest stay in this row in elapsed time. Compare it with the average to spot the outliers behind it.
    Min Business Minutes Min_Business_Minutes__c Number (16, 2) The shortest single Interval this row counts, in business minutes (time inside its Business hours); 0 when a stay fell wholly outside its hours. Kept by the nightly Summaries job as it adds Intervals to the row; blank while no counted Interval has business minutes.
    Help text: The shortest stay in this row, inside Business hours. A 0 means a stay began and ended outside Business hours.
    Min Calendar Minutes Min_Calendar_Minutes__c Number (16, 2) The shortest single Interval this row counts, in calendar minutes (elapsed clock time). Kept by the nightly Summaries job as it adds Intervals to the row; blank while no counted Interval has calendar minutes.
    Help text: The shortest stay in this row in elapsed time, nights and weekends included.
    Owner Id Owner_Id__c Text (18) The 18-character Id of the user or queue that owned the records during the Intervals this row counts, copied from each Interval's Owner Id; part of the row's key, so each owner has rows of their own. Blank on an all-owners row. Written by the nightly Summaries job. Sojourn Dashboards group and filter owner charts by it.
    Help text: The user or queue that owned the records during these stays. Blank when All Owners is checked.
    Owner Name Owner_Name__c Text (255) The display name of the user or queue in Owner Id, copied from the first Interval that created the row; a later rename does not change rows already written. Blank on an all-owners row. Written by the nightly Summaries job; owner charts in Sojourn Dashboards and the Owner Leaderboard report show it.
    Help text: Name of the user or queue these stays belonged to, as it was when the row was first built. Blank when All Owners is checked.
    Owner Type Owner_Type__c Picklist: User, Queue Whether the owner in Owner Id is a user or a queue. Allowed values: User, Queue. Copied from the counted Intervals by the nightly Summaries job; blank on an all-owners row. The Owner Leaderboard report keeps User rows only.
    Help text: User or Queue. Filter to User to rank people; Queue rows show time records waited in a queue.
    Owner User Owner_User__c Lookup (User) The owner as a lookup to User, set only when Owner Id is a user; blank for a queue owner and on an all-owners row. Lets a report on Interval Summaries reach the user's role, manager, and other user fields. Written by the nightly Summaries job.
    Help text: The owning user as a lookup, so a report can group by role or manager. Blank for queues and on all-owners rows.
    Parent Object Parent_Object__c Text (255) The API name of the Tracked object whose Intervals this row counts, for example Case or Work_Order__c; part of the row's key. Copied from the counted Intervals by the nightly Summaries job. Sojourn Dashboards and the summary reports filter on it to keep one object's rows.
    Help text: The object these stays belong to, such as Case. Filter on it so a report shows one object.
    Period Start Period_Start__c Date The first day of the period this row covers: for a Day row, the day the counted Intervals ended; for a Month row, the first day of that month. Days follow the org's time zone. Part of the row's key. Sojourn Dashboards filter on it for their date range, Rebuild summaries replaces the rows of whole months by it, and a purge deletes old Day rows by it.
    Help text: The day, or the first day of the month, these stays ended in. Use it as the date in trend reports and date filters.
    Record Closed Record_Closed__c Checkbox Checked when the Intervals this row counts were time spent while their record was closed (each Interval's Record Closed, set by the object's Closed when rule), so closed time is kept in rows of its own; part of the row's key. Unchecked by default. Sojourn Dashboards and the Average Hours per Status by Week report leave these rows out.
    Help text: Checked when this row counts time spent while the record was already closed. Filter it out to see working time only.
    Record Count Record_Count__c Number (9, 0) How many distinct tracked records the counted Intervals belong to, counting each record once per row in each Summaries run. A record whose Intervals reach the same row in two runs, such as on two nights of one month, is counted again, so the figure can be above the true distinct count, most often on Month rows. Rebuild summaries counts each record once per row. Written by the nightly Summaries job.
    Help text: Records behind the stays in this row. A record added on two different nights counts twice, so read it as approximate on Month rows.
    Record Type Record_Type__c Text (255) Reserved for the record type of the counted records, as one of the ten parts of the row's key. Always blank today: no Sojourn setting splits summaries by record type yet. Because the key already holds the part, a later split needs only Rebuild summaries, not new rows.
    Help text: Blank today: Sojourn does not split summaries by record type yet.
    Snapshot 1 Snapshot_1__c Text (255) Reserved for the first Snapshot field's value of the counted Intervals, as one of the ten parts of the row's key. Always blank today: no Sojourn setting splits summaries by a Snapshot field yet. Because the key already holds the part, a later split needs only Rebuild summaries, not new rows.
    Help text: Blank today: Sojourn does not split summaries by a Snapshot field yet.
    Sum Business Minutes Sum_Business_Minutes__c Number (16, 2) The total business minutes of the Intervals this row counts: the time inside each Interval's Business hours, added up. Blank until an Interval with business minutes is added. Added to by the nightly Summaries job. Sojourn Dashboards and the summary reports, such as Average Hours per Status by Week, add it across rows and divide by Interval Count for averages.
    Help text: Total time inside Business hours across this row's stays. Add it across rows and divide by Interval Count for a true average.
    Sum Calendar Minutes Sum_Calendar_Minutes__c Number (16, 2) The total calendar minutes of the Intervals this row counts: the elapsed clock time from each Interval's Entered At to its Exited At, nights and weekends included, added up. Blank until an Interval with calendar minutes is added. Added to by the nightly Summaries job; Sojourn Dashboards add it across rows.
    Help text: Total elapsed time across this row's stays, nights and weekends included. Divide by Interval Count for the average.
    To Value To_Value__c Text (255) The value of the Tracked field the counted Intervals held, as each Interval stores it: a picklist's API value, the text of a text field, or the display name for an owner or lookup field. Part of the row's key; blank when the Intervals held a blank value. Copied by the nightly Summaries job. Reports and Sojourn Dashboards group by it for time per status, stage, or owner.
    Help text: The status, stage, owner, or other value these stays were in. Group by it to see time per value.
    Tracked Field Tracked_Field__c Text (255) The API name of the Tracked field whose Intervals this row counts, for example Status or OwnerId; part of the row's key. Copied from the counted Intervals by the nightly Summaries job. Each Tracked field has rows of its own, so Sojourn Dashboards and the packaged summary reports always filter on it before grouping by To Value.
    Help text: The field these stays measure, such as Status or OwnerId. Filter on one field first, then group by To Value.
    Unique Code Unique_Code__c Text (255) The row's key, set by the Summaries job so each combination has exactly one row: the 64-character lowercase hex SHA-256 of ten parts joined by pipes, each written as its length, a colon, and its text (a blank part is 0:). The parts are Granularity, Period Start (yyyy-MM-dd), Parent Object, Tracked Field, To Value, Owner Id (an asterisk on an all-owners row), Value Group, Record Type, Snapshot 1, and Record Closed (closed, or blank). Each run reads the stored rows by this code and adds to them.
    Help text: Set by the Summaries job to keep one row per period, object, field, value, owner, and the other key parts. Do not edit it: the next run would start a second row for the same combination.
    Value Group Value_Group__c Text (255) The value group of the counted Intervals, copied from each Interval's Value Group: a named set of the Tracked field's values, such as Backlog for New and Reopened. Part of the row's key. Blank when the Intervals carry no value group, as every Interval does until value groups are set up for its field. Sojourn Dashboards can group a chart by it.
    Help text: The named group of values these stays count toward. Blank when the field has no value groups.
    Warning Count Warning_Count__c Number (9, 0) How many of the Intervals this row counts were warnings (the Interval's Is Warning): their business minutes reached their warn minutes, the Goal's Warn At Percent of its target. A breached Interval is also a warning when its Goal has a Warn At Percent. A whole number, 0 when none. Added to by the nightly Summaries job.
    Help text: Stays in this row that reached their Goal's Warn at percent. A Breach also counts here when its Goal sets a warn percent.

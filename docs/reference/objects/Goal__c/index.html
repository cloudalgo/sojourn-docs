    Goal

    The Goal object sets how long a record should stay in one value of a tracked field, as a child of Tracked Object. It holds the Value, Target Business Minutes (required), Warn At Percent, an optional Tracked Field, and an Active switch. Intervals that pass the target are flagged as breached. Commonly used for status and stage service targets.

    API name: Goal__c

    Field API name Type Description
    Active Is_Active__c Checkbox Whether this goal is applied to new intervals.
    Help text: Inactive goals are kept for history but not applied to new intervals.
    Target Business Minutes Target_Business_Minutes__c Number (16, 2) The business minutes an interval in this value may last before it is breached.
    Help text: An interval in this value should end within this many business minutes.
    Tracked Field Tracked_Field__c Lookup (Tracked_Field__c) The tracked field whose values this goal measures.
    Help text: The tracked field this goal applies to, for example Status.
    Tracked Object Tracked_Object__c Master-detail (Tracked_Object__c) The tracked object this goal applies to.
    Value Value__c Text (255) The field value the goal applies to, or an asterisk for any value.
    Help text: The status or stage value, or * for any value.
    Warn At Percent Warn_At_Percent__c Number (3, 0) Percentage of the target at which an interval shows as at risk.
    Help text: Flag as at risk at this percentage of the target. Default 80.

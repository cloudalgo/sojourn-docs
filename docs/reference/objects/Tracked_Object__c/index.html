    Tracked Object

    The Tracked Object object lists each Salesforce object Sojourn watches. It holds the Object API Name (required, external ID), the Active switch, the status field and Closed when rule, business hours overrides, snapshot fields, the record type filter, Live values settings, the pause and Catch up window, and Backfill mode and status. The capture engine and every job read it with its Tracked fields and Goals. Set in Sojourn Settings; Case, Lead, and Opportunity are on every plan, and any other object needs the Plus plan.

    API name: Tracked_Object__c

    Field API name Type Description
    Backfill Message Backfill_Message__c LongTextArea (32768) The result of the last Backfill on this Tracked object, in words: for a finished run, the mode, when it finished, and how many Intervals it wrote for how many records, for example "Seed backfill on 3 Oct 2026, 14:20: 400 Intervals for 200 records."; for a failed run, why, and how many chunks failed with a pointer to the Error Log. Blank before the first Backfill and while a run is queued. Written by the Backfill job when it finishes, and by a Fresh start at once. Shown on the object's Backfill tab in Sojourn Settings. Kept apart from Catch Up Message, so a Catch up never hides it.
    Help text: The last Backfill result, written by Sojourn. A failed run says why; the records it could not import are in the Error Log. Run Backfill again from the object's Backfill tab.
    Backfill Mode Backfill_Mode__c Picklist: History, Seed, Fresh The mode of the last Backfill started on this Tracked object. One of History (rebuild past Intervals from the object's native field history, where the object keeps it), Seed (open one Interval per Tracked field from each record's current value, starting now), or Fresh (add nothing; capture begins with the next change). New rows start as History, though no Backfill has run until Backfill Status says so. Set by Run backfill on the object's Backfill tab of Sojourn Settings and read by the Backfill job and the Jobs screen. History and Seed need the Plus plan; Fresh works on every plan.
    Help text: How the last Backfill gave existing records their Intervals. History imports native field history, Seed opens an Interval from current values, and Fresh starts empty. Choose the mode when you run Backfill on the object's Backfill tab.
    Backfill Status Backfill_Status__c Picklist: None, Queued, Running, Complete, Failed Where the last Backfill on this Tracked object stands. One of None (no Backfill yet, the default), Queued (the job is waiting to start), Running, Complete, or Failed (the reason is in Backfill Message). Set by Run backfill and by the Backfill job as it starts and finishes; a Fresh start goes straight to Complete. A stored Queued or Running blocks a new Backfill only while a Backfill job is really running, so a run that died and left it behind does not block the next one. Shown on the Tracked objects list, the object's Backfill tab, and the Health Monitor.
    Help text: Updated by the Backfill job. Failed means the reason is in Backfill Message. Run Backfill from the object's Backfill tab in Sojourn Settings.
    Business Hours Id Business_Hours_Id__c Text (18) The business hours for this Tracked object, as an 18-character BusinessHours Id. Blank: the default business hours in Sojourn Settings, then the org's default. Read whenever business minutes are worked out for this object's Intervals, after the Tracked field's business hours, the record's business hours field, and the owning queue's mapping, so it is the fourth choice of six. Set on the object's Records tab of Sojourn Settings, or by a settings file import, which matches business hours by name.
    Help text: Business hours used for this object when no field, record, or queue setting applies. Leave blank for the default business hours in Sojourn Settings. A change applies to stays measured from then on.
    Business Hours Source Field Business_Hours_Source_Field__c Text (255) The API name of a field on the tracked record that holds a BusinessHours Id, for example BusinessHoursId on Case. Blank: no record-level business hours. Read for each Interval of this object, after the Tracked field's business hours and before the owning queue's mapping and the object's business hours, so a record can carry its own hours, such as a region's. A value that is not a BusinessHours Id is passed over. Checked against the object's fields when saved on the object's Records tab of Sojourn Settings or by a settings file import.
    Help text: API name of a field on the record that holds a business hours Id, for example BusinessHoursId on Case. Set it when each record says which hours apply; it wins over queue and object business hours.
    Capture Mode Capture_Mode__c Picklist: Trigger, Flow A note for admins on how changes to this object reach Sojourn. One of Trigger or Flow; new rows start as Flow. Sojourn's code never reads or writes it and capture does not depend on it: Case, Lead, and Opportunity are always captured by the packaged triggers, and any other object needs an active record-triggered Flow cloned from the Sojourn Capture Template. Sojourn Settings does not show or set it; set it on the record page if you want the record to say which path the object uses.
    Help text: For your notes only; Sojourn does not read it. Case, Lead, and Opportunity use the packaged trigger. Other objects use a Flow cloned from the Sojourn Capture Template.
    Catch Up Message Catch_Up_Message__c LongTextArea (2000) The result of the last Catch up on this Tracked object, in words: when it finished, how many records it replayed, and anything still waiting, for example a pause during the run or chunks that stopped (with a pointer to the Error Log). Blank before the first Catch up. Written by the Catch up job when it finishes; a complete run also clears Paused Since. Shown as Last Catch up on the object's Backfill tab in Sojourn Settings. Kept apart from Backfill Message, so a Catch up never hides the last Backfill result.
    Help text: The last Catch up result, written by Sojourn. If it stopped, or capture was paused during it, run Catch up again: records already replayed are skipped.
    Closed Checkbox Field Closed_Checkbox_Field__c Text (80) The API name of a checkbox field on the tracked object that means the record is closed while it is checked, for example IsClosed on Opportunity; any checkbox but IsDeleted. Blank: the status field's Closed Values decide instead. Read by capture, Backfill, Catch up, the nightly reconcile, Live values, and the Case figures to tell whether a record is closed: closed records' Intervals are marked Record Closed, Live values skips them, and reports of open stays leave them out. A name that is not a checkbox on the object is ignored with an Error Log row. Set under Closed when on the object's Records tab of Sojourn Settings, or by a settings file import.
    Help text: Set it under Closed when on the object's Records tab, for example IsClosed on Opportunity. A record counts as closed while the checkbox is checked. Leave blank to use the status field's closed values.
    Closed Values Closed_Values__c LongTextArea (1000) The values of the object's status field that mean the record is closed, as API values separated by commas, for example Closed,Resolved. Used only when Closed Checkbox Field is blank. Blank: for Case with Status as its status field, the case statuses marked Closed in Setup; for any other object, no record counts as closed. Read by capture, Backfill, Catch up, the nightly reconcile, Live values, and the Case figures: closed records' Intervals are marked Record Closed, Live values skips them, and reports of open stays leave them out. Set under Closed when on the object's Records tab of Sojourn Settings, or by a settings file import.
    Help text: Values of the status field that mean closed, for example Closed and Resolved. A record in one of them counts as closed. Leave blank on Case to use the statuses Setup marks closed.
    History Chunk Size History_Chunk_Size__c Number (2, 0) How many records a History Backfill on this object reads in each chunk. A whole number from 5 to 50; blank means 20. Read when a History Backfill starts, as its job's batch size; each chunk reads every field history row of its records, so fewer suit records with long field history. Seed Backfills do not use it. Set on the object's Advanced tab of Sojourn Settings or by a settings file import; changing it needs the Plus plan, since Backfill does.
    Help text: Records a History Backfill reads in each chunk, 5 to 50; blank for 20. Lower it when records have long field history and History Backfill stops on limits.
    Ignore Queue Member Moves Ignore_Queue_Member_Moves__c Checkbox When checked, a move between two users who are both direct members of the same queue that takes this object keeps the open owner Interval open with its first owner, and no new owner Interval opens; a move to anyone else opens a new one as usual. Off by default: every owner change opens a new owner Interval. Only direct user members of the queue count; nested groups and roles are not read. Leave it off when reports should show time per person. Applies from each record's next owner change; existing Intervals are never rewritten. Set on the Values tab of the object in Sojourn Settings.
    Help text: On: passing a record between members of the same queue keeps one owner stay, so time counts for the team, not each person. Leave off for time per person.
    Active Is_Active__c Checkbox Whether Sojourn tracks this object. A checkbox, on by default. Read on every save of the object's records and by the jobs: inactive, no new Intervals are written for it, Backfill and Catch up refuse to start, and the Intervals already written stay. An object beyond Case, Lead, and Opportunity is tracked only on the Plus plan, whatever this says. Set in Sojourn Settings, or by a settings file import.
    Help text: Sojourn records stays only for active Tracked objects. Turn it off to stop tracking the object and keep its history.
    Last Paused At Last_Paused_At__c DateTime When capture on this object was last paused, stamped by Sojourn each time Pause Capture is turned on. Blank until the first pause. Read when Catch up finishes: a pause after the run began means some changes may not have been replayed, so Paused Since is kept and the result says to run Catch up again. Paused Since keeps the earliest pause not yet caught up; this field keeps the latest.
    Help text: Set by Sojourn each time capture is paused. Paused Since keeps the earliest pause not yet caught up.
    Live Owner Minutes Field Live_Owner_Minutes_Field__c Text (255) The API name of a Number field on the tracked record that Live values writes with the business minutes the record has spent with its current owner, for objects other than Case, Lead, and Opportunity, which use Sojourn's own Owner Business Minutes field. Blank: no owner minutes are written to the record. Each Live values run writes it for open records within the Live values window, on the Plus plan with Live values on; closed records are not written. Checked against the object's fields when saved on the object's Live values tab of Sojourn Settings or by a settings file import.
    Help text: API name of a Number field on the record. Each Live values run writes the business minutes with the current owner to it, so list views and reports can show them. Plus plan.
    Live State Minutes Field Live_State_Minutes_Field__c Text (255) The API name of a Number field on the tracked record that Live values writes with the business minutes the record has spent in the current value of its status field, for objects other than Case, Lead, and Opportunity, which use Sojourn's own State Business Minutes field. Blank: no state minutes are written to the record. Each Live values run writes it for open records within the Live values window, on the Plus plan with Live values on; closed records are not written. Checked against the object's fields when saved on the object's Live values tab of Sojourn Settings or by a settings file import.
    Help text: API name of a Number field on the record. Each Live values run writes the business minutes in the current status to it, so list views and reports can show them. Plus plan.
    Live Values Enabled Live_Values_Enabled__c Checkbox Whether the Live values job refreshes this object's open Intervals and its record's live minute fields. A checkbox, off by default. Read at the start of every Live values run: the run covers an object that is not paused, is on the org's plan, and has this on or has active Goals. Breach and warning flags are refreshed on every plan; writing the minute fields to the record needs the Plus plan. Set on the object's Live values tab of Sojourn Settings, or by a settings file import.
    Help text: On: each Live values run refreshes the minutes to date of this object's open stays and writes the live minute fields on the record (Plus plan). Goals are flagged either way.
    Lookup Field Override Lookup_Field_Override__c Text (255) The API name of the lookup on Interval to fill with the tracked record, for when more than one lookup on Interval points at this object. Blank: Sojourn fills the lookup named after the object, or else the first lookup to it. Read whenever an Interval of this object is written; a name that is not a lookup on Interval to the object is refused on save, and if one later stops being one Sojourn fills the automatic choice instead. Lets you add your own lookups to Interval without a package change. Set on the object's Advanced tab of Sojourn Settings or by a settings file import.
    Help text: API name of the lookup on Interval to fill when more than one points at this object. Leave blank and Sojourn fills the lookup named after the object.
    Name Field Name_Field__c Text (255) The API name of the field whose value names the record on its Intervals, for example CaseNumber or Name. Blank: the object's own name field. Read when an Interval opens, which copies the value into Parent Name for reports and Sojourn Dashboards; a later change to the field does not change Intervals already written. The field must be one the admin saving it can read. Set on the object's Records tab of Sojourn Settings or by a settings file import.
    Help text: Field shown as the record's name on stays, for example CaseNumber or Name. Leave blank for the object's own name field. Applies to stays that begin after you change it.
    Object API Name Object_API_Name__c Text (255) The API name of the Salesforce object this row tracks, for example Case or Work_Order__c. Required and unique, matched without regard to case; it is the key the capture engine, the jobs, and a settings file import match on. Checked against describe when the row is saved: the object must be one Sojourn can track, and an object other than Case, Lead, and Opportunity needs the Plus plan. Set when the object is added on the Tracked objects screen of Sojourn Settings.
    Help text: API name of the tracked object, for example Case or Work_Order__c. Set when you add the object in Sojourn Settings.
    Owner Tracking Owner_Tracking__c Text (20) Which owners get an owner Interval on this Tracked object. Allowed values: blank for users and queues (the default), Users for users only, or Queues for queues only. Any other value is refused on save and on import, and Sojourn reads it as blank. With Users, no owner Interval opens while a queue owns the record, and the user's stay closes when the record moves to a queue; with Queues it is the reverse. Applies when Track Owner is on, from each record's next owner change; existing Intervals are never rewritten. Set on the Values tab of the object in Sojourn Settings.
    Help text: Blank tracks time with users and queues. Users tracks only users; Queues tracks only queues. Applies from each record's next owner change.
    Pause Capture Pause_Capture__c Checkbox Pauses live capture for this object, for a bulk import or a data fix. A checkbox, off by default. While on, saves of the object's records write no Intervals, the nightly reconcile does not repair the object's values, Live values skips it, and Catch up refuses to start. Turning it on stamps Last Paused At and, unless an earlier pause is still waiting, Paused Since. After turning it off, run Catch up: it replays the records changed since Paused Since at their own times. Set from the Tracked objects screen or the object's screen in Sojourn Settings.
    Help text: Turn on before a bulk import. Sojourn skips this object until you turn it off; then run Catch up to record what changed meanwhile.
    Paused Since Paused_Since__c DateTime The start of the pause window Catch up replays: when capture was paused, kept from the earliest pause not yet caught up. Blank when nothing is waiting. Set by Sojourn when Pause Capture is turned on and this is blank; read by Catch up, which replays the records changed since then, and cleared when a Catch up completes with no pause during the run. While it has a value, the object is active, and capture is on again, Sojourn Settings offers Catch up for the object.
    Help text: Set when capture is paused. Catch up replays records changed since this time, then clears it.
    Record Criteria Record_Criteria__c LongTextArea (4000) Conditions a record must meet for Sojourn to record its changes, as JSON: a list of conditions, each a field API name, an operator of equals or notEquals, and a value, for example [{"field": "Type", "operator": "equals", "value": "Problem"}]. Every condition must hold. Fields are picklist, checkbox, or short text fields of the object; names are checked against the object's fields, and values are always bound, never added to a query. Blank, the default, means every record is tracked. Checked on the record's values after the save, like the record type filter: a record that does not match is skipped and its open Intervals stay open; when it matches again its next change is recorded, and Reconcile drift repairs what changed meanwhile. Set on the Records tab of the object in Sojourn Settings, which checks the JSON on save and on import.
    Help text: Only records that meet every condition, such as Type equals Problem, are tracked. A record that stops matching keeps its Intervals; its new changes are not recorded until it matches again.
    Record Type Filter Record_Type_Filter__c LongTextArea (1000) The record types to track, as record type developer names separated by commas, for example Support,Billing. Blank: every record, with or without a record type. Read on every save of the object's records and by the jobs: with names listed, a record is tracked only while its record type is one of them, and a record with no record type is not tracked. Set under Record types on the object's Records tab of Sojourn Settings, or by a settings file import.
    Help text: Record type developer names to track, separated by commas. Leave blank to track every record. Records of other record types get no stays.
    Record Type Hours Record_Type_Hours__c LongTextArea (4000) Business hours for each record type of this Tracked object, as JSON from a record type developer name to a business hours Id, for example {"Support_EMEA": "the Id of the EMEA business hours"}. Blank, the default, or a record type not listed, falls through to the next step of the Business hours order. In that order the record type step comes after the record's business hours field and before the queue's business hours. The settings file writes record types by developer name and business hours by name. Applies to Intervals that open after the change; existing Intervals keep their business hours. Set on the Records tab of the object in Sojourn Settings, which checks the JSON on save and on import.
    Help text: Uses different Business hours for each record type, such as EMEA support hours for EMEA cases. Record types not listed use the next step in the Business hours order.
    Retention Days Retention_Days__c Number (4, 0) Days of closed Intervals to keep for this Tracked object when Retention Mode is Days, a whole number from 30 to 3,650. Blank by default; ignored for any other mode. A purge run deletes this object's closed Intervals that ended more than this many days ago, only through the typed confirmation of the Retention and purge screen. Plus plan. Not carried in the settings file. Set on the Advanced tab of the object in Sojourn Settings.
    Help text: How many days to keep this object's closed Intervals, 30 to 3,650, when Retention Mode is Days.
    Retention Mode Retention_Mode__c Text (20) How long this Tracked object's closed Intervals are kept when purge runs. Allowed values: blank to use the org's retention (the default), Days to keep the number of days in Retention Days, or Everything to keep every Interval of this object. Any other value is refused on save, and Sojourn reads it as blank. A purge run deletes each object's closed Intervals by its own window, only through the typed confirmation of the Retention and purge screen, and skips objects set to Everything; nothing is deleted outside that run. Plus plan. Not carried in the settings file. Set on the Advanced tab of the object in Sojourn Settings.
    Help text: Blank uses the org's retention. Days keeps this object's Intervals for the days you set; Everything keeps them all. Purge deletes only through its confirmed run.
    Snapshot Fields Snapshot_Fields__c LongTextArea (1000) Up to five field API names on the tracked object, separated by commas, for example Priority,Origin, whose values are copied onto each Interval as Snapshot 1 to Snapshot 5, in that order, when the Interval opens. Lets reports group time by a field Sojourn does not track. Blank: the snapshot fields stay blank. A name the object no longer has is passed over; a later change to the record does not change Intervals already written. Each field must be one the admin saving it can read. Set under Snapshot fields on the object's Records tab of Sojourn Settings, or by a settings file import.
    Help text: Up to five field API names, separated by commas, copied onto each stay as Snapshot 1 to 5 when it begins, for example Priority or Region. Applies to stays that begin after you change it.
    Status Field Status_Field__c Text (255) The API name of the object's main status or stage field, for example Status or StageName. Blank: Status on Case, and no status field on any other object. Closed Values are values of this field; Goals with no Tracked field apply to it; Live values writes its state minutes from its Intervals; and Sojourn Dashboards and the Goals screen name it as the status field. Set on the object's Records tab of Sojourn Settings or by a settings file import; it should also be a Tracked field of the object.
    Help text: API name of the main status or stage field, for example Status or StageName. Closed values and Goals without a field refer to it.
    Track Owner Track_Owner__c Checkbox Whether time with each owner is tracked. A checkbox, on by default. When the row is saved, Sojourn adds or turns on an Owner Tracked field (OwnerId) for the object when it is on, and turns that row off when it is off; the row is never deleted, so its Intervals stay. The Owner field counts toward the ten active Tracked fields per object. Set on the object's Fields tab of Sojourn Settings, or by a settings file import.
    Help text: On: Sojourn also records how long each record spends with each owner, users and queues. Off: the Owner field stops recording and keeps its history.

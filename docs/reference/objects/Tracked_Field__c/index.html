    Tracked Field

    The Tracked Field object names one field Sojourn watches on a Tracked Object, such as Status or Owner, as a child of Tracked Object. It records the Field API Name, Field Label, Field Type, an Active switch, an optional business hours override, Start At First Value, and a Unique Code set automatically. Each active row produces Intervals; at most ten fields of one object are active, and rows are switched off rather than deleted. Set on the object's Fields tab in Sojourn Settings.

    API name: Tracked_Field__c

    Field API name Type Description
    Business Hours Id Business_Hours_Id__c Text (18) The business hours for this one Tracked field, as an 18-character BusinessHours Id, for example 24x7 hours for a field timed around the clock. Blank: the field inherits, and the record's business hours field, the owning queue's mapping, the Tracked object's business hours, and the default in Sojourn Settings apply in that order. Read first, before any of those, whenever business minutes are worked out for this field's Intervals. Set per field on the object's Fields tab of Sojourn Settings, or by a settings file import, which matches business hours by name.
    Help text: Business hours used for this field only, overriding every other business hours setting. Leave blank to inherit. A change applies to stays measured from then on.
    Excluded Values Excluded_Values__c LongTextArea (1000) Values of this Tracked field that do not count, one value per line, as the field stores them (the API value, not the label). Blank, the default, means every value counts. When a record changes into an excluded value, Sojourn closes the open Interval at the change and opens none; when the record moves on to a counted value, the next Interval opens with the excluded value as its From value. One rule applies on every path that opens an Interval: trigger and Flow capture, History and Seed backfill, Catch up, Reconcile drift, and repairs. Closed values and blank cannot be excluded, and a Goal cannot be set on an excluded value. Set on the Values tab of the object in Sojourn Settings, which checks it on save and on import; it applies from the next change on each record and never rewrites an existing Interval. Each line break counts as two characters.
    Help text: Values that do not count, one per line. Time in them is not measured: the stay before closes at the change, and no Interval opens until the record moves to a counted value. Applies from each record's next change.
    Field API Name Field_API_Name__c Text (255) The API name of the field Sojourn records, for example Status, StageName, or OwnerId, on the parent Tracked object. Required. Read by the capture engine on every save to compare old and new values, and checked against describe each time the configuration loads: a field the object no longer has is passed over with an Error Log row. Together with the object's API name it makes Unique Code. Set when the field is chosen on the object's Fields tab of Sojourn Settings, or by a settings file import.
    Help text: API name of the field, for example Status or OwnerId. Set when you choose the field in Sojourn Settings.
    Field Label Field_Label__c Text (255) The field's label, copied from describe when the field is chosen or turned back on, for example Status. Blank: the field's current label from describe is used. Copied onto each new Interval as Tracked Field Label, and shown in Sojourn Settings, the Goals screen, and Sojourn Dashboards. Renaming the field in Setup does not change it until the field is turned off and on again; editing it here changes the label on Intervals that open afterwards.
    Help text: Label shown on stays and in Sojourn Settings, copied from the field's label. Edit it to show a different name on new stays.
    Field Type Field_Type__c Picklist: Picklist, Lookup, Owner, Text, Checkbox, Date The kind of field, set by Sojourn from describe when the field is chosen or turned back on. One of Picklist (picklists and multi-select picklists), Lookup, Owner (OwnerId), Text (text, email, phone, and URL up to 255 characters), Checkbox, or Date (date and date/time). New rows default to Picklist. Owner makes the field an owner field: its Intervals carry the owner's name and type, and Start At First Value is ignored. How each value is stored on an Interval follows describe.
    Help text: Set by Sojourn from the field's type. Picklist stays hold the API value; Lookup and Owner stays hold the display name and Id.
    Goal Split Field Goal_Split_Field__c Text (80) API name of a picklist or checkbox field on the Tracked object that splits this Tracked field's Goals, for example Priority, so one value can have a different Goal for each priority. Blank, the default, means the Goals are not split. The name is checked against the object's fields on save and on import. When an Interval opens, Sojourn reads this field on the record and picks the most specific Goal: the value with the record's split value, then the value with any split value, then Any value with the record's split value, then Any value with any split value. An open Interval keeps its Goal when the split field changes later. Set on the Goals screen of Sojourn Settings.
    Help text: A picklist or checkbox field, such as Priority, whose value picks a different Goal for the same value. Leave blank for one Goal per value.
    Active Is_Active__c Checkbox Whether this field currently produces Intervals. A checkbox, on by default. Inactive rows are skipped when the configuration loads, so their records' changes write no new Intervals; the Intervals already written stay. Rows are never deleted: removing a field in Sojourn Settings turns it off, and choosing it again turns the same row back on with its current label and type. At most ten fields of one Tracked object can be active, the Owner field included. Set on the object's Fields tab, or by Track Owner for the Owner field.
    Help text: Inactive fields keep their history but stop producing new stays. At most ten fields per object can be active.
    Start At First Value Start_At_First_Value__c Checkbox Whether timing waits for the field's first value. A checkbox, on by default. On: a field that is blank when the record is created, or at a Seed Backfill, gets no Interval until it first has a value, and that first Interval has a blank From Value. Off: the time the field spends blank is measured too, as an Interval with a blank To Value, for example time unassigned. Read by capture, Backfill, Catch up, and the nightly reconcile. The Owner field ignores it. Set per field on the object's Fields tab of Sojourn Settings, or by a settings file import.
    Help text: On: timing starts when the field first has a value. Off: time spent blank is measured too, for example time before a priority is set.
    Tracked Object Tracked_Object__c Master-detail (Tracked_Object__c) The Tracked object this field belongs to, as the master record: deleting the Tracked object deletes its Tracked fields. Required. Its Object API Name and this row's Field API Name make Unique Code, and its settings (business hours, Closed when, Goals) apply to this field's Intervals. Set when the field is chosen in Sojourn Settings.
    Help text: The Tracked object this field belongs to. Set by Sojourn Settings.
    Unique Code Unique_Code__c Text (255) The key of this row: the Tracked object's API name, a dot, and the field's API name, for example Case.Status. Unique and matched without regard to case, so an object can track a field only once. Set by Sojourn before every insert and update; do not edit it.
    Help text: Set automatically as the object API name, a dot, and the field API name, for example Case.Status.
    Value Colours Value_Colours__c LongTextArea (4000) The colour of each value of this Tracked field on the Sojourn timeline, as JSON from a value to a palette colour name, for example {"New": "Tide", "Waiting on Customer": "Slate"}. The allowed names are Tide, Harbor, Slate, and Mist; Coral and Lantern are kept for Breach and the current Interval. Blank, the default, a value not listed, or a name outside the list takes the palette in order. Only the timeline reads it: it changes no Interval, summary, or Goal. Set on the Values tab of the object in Sojourn Settings, which checks the JSON on save and on import.
    Help text: Chooses the timeline colour of each value from Tide, Harbor, Slate, and Mist. Values without a colour take the palette in order. Changes only how the timeline looks.
    Value Groups Value_Groups__c LongTextArea (4000) Named groups of this Tracked field's values, as JSON: a list of groups, each with a name of up to 80 characters and its values, for example [{"name": "Backlog", "values": ["New", "Escalated"]}]. A value belongs to at most one group; a value in no group has no group. Blank, the default, means no groups. When an Interval opens, Sojourn writes the group of its value to the Interval's Value Group field, and summaries and reports count the values of a group together. A group change applies to Intervals that open after it: existing Intervals keep the group they were stored with, and Rebuild summaries counts them as stored. Set on the Values tab of the object in Sojourn Settings, which checks the JSON on save and on import.
    Help text: Puts values under one name, such as Backlog for New and Escalated, so reports and summaries count them together. Each value can be in one group. Applies to Intervals that open after the change.
    Values Hidden Values_Hidden__c Checkbox When checked, new Intervals of this Tracked field keep only that the value changed: the From value, To value, To label, To Id, and value group stay blank, while the minutes, the owner, and the Goals of other fields are still measured. The timeline shows such a stay as (hidden). Off by default: values are stored. It cannot be turned on while the field has active Goals, and the Goals screen does not offer the field while it is on. Set on the Values tab of the object in Sojourn Settings; it applies to Intervals that open after the change and never clears values already stored.
    Help text: On: Sojourn keeps how long each stay lasted but not which value it was, for fields whose values should not be copied. Applies to new Intervals only.

    Interval Archive

    Closed Intervals that a purge run removed from the Interval object, with the same values and minutes. Indexed by Parent Id, Tracked Field, Entered At (newest first), and Sequence; Parent Object is stored but not indexed. The timeline reads it for records older than the retention period.

    API name: Interval_Archive__b

    Field API name Type Description
    Breach Flag Breach_Flag__c Number (1, 0) 1 when the interval breached its goal, else 0. Big objects have no checkbox type.
    Business Minutes Business_Minutes__c Number (16, 2) Elapsed business minutes between Entered At and Exited At.
    Calendar Minutes Calendar_Minutes__c Number (16, 2) Elapsed minutes between Entered At and Exited At.
    Entered At Entered_At__c DateTime When the record entered this value.
    Exited At Exited_At__c DateTime When the record left this value.
    From Value From_Value__c Text (255) Value before this interval.
    Goal Minutes Goal_Minutes__c Number (16, 2) Target business minutes that applied to the interval.
    Original Interval Name Original_Interval_Name__c Text (30) Auto-number of the interval before it was archived.
    Owner Id Owner_Id__c Text (18) Owner of the record during this interval.
    Owner Name Owner_Name__c Text (255) Owner display name during this interval.
    Owner Type Owner_Type__c Text (10) User or Queue.
    Parent Id Parent_Id__c Text (18) Id of the tracked record.
    Parent Name Parent_Name__c Text (255) Record name or number at capture time.
    Parent Object Parent_Object__c Text (255) API name of the tracked object, in full.
    Record Closed Flag Record_Closed_Flag__c Number (1, 0) 1 when the interval was time spent while its record was closed (the Interval's Record Closed), else 0 (D-729). Summary rows key on it. Big objects have no checkbox type.
    Help text: 1 when the record was closed during this stay, else 0. Big objects have no checkbox type.
    Sequence Sequence__c Number (9, 0) Order of the interval within its record and field; keeps two intervals entered in the same second distinct.
    Source Source__c Text (40) How the interval was created.
    To Value Id To_Value_Id__c Text (18) Id behind the value for lookup and owner fields.
    To Value Label To_Value_Label__c Text (255) Picklist label at capture time.
    To Value To_Value__c Text (255) Value held during this interval.
    Tracked Field Tracked_Field__c Text (60) API name of the tracked field in full; 60 characters fits any namespaced field name.
    Value Group Value_Group__c Text (255) The value group the interval's value belonged to, for example Backlog (D-675, D-729). Summary rows key on it. Blank when the field had no value groups.
    Help text: The named group of values this stay counted toward. Blank when the field had no value groups.
    Warn Minutes Warn_Minutes__c Number (16, 2) Business minutes at which the interval became a warning: its goal's warn percent of the target, copied when it began.
    Help text: Business minutes at which the interval became a warning.
    Warned At Warned_At__c DateTime When the interval's business minutes reached its warn minutes, in its business hours. Blank when it was never a warning.
    Help text: When the interval became a warning. Blank when it never was.
    Warning Flag Warning_Flag__c Number (1, 0) 1 when the interval was a warning (its business minutes reached its warn minutes), else 0. Big objects have no checkbox type.
    Help text: 1 when the interval was a warning, else 0. Big objects have no checkbox type.

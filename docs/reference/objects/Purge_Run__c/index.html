    Purge Run

    The Purge Run object logs one admin-requested purge of closed intervals older than a retention window, with Retention Days, Cutoff Date, Status, and the counts archived and deleted. The CSV export is attached as a file. Commonly used to audit what left the org and when.

    API name: Purge_Run__c

    This object is used by archive and purge, a release 1 feature that is not active yet.

    Field API name Type Description
    Archived Count Archived_Count__c Number (9, 0) Intervals copied to the archive.
    Help text: Intervals copied to the Interval Archive big object.
    Cutoff Date Cutoff_Date__c DateTime Intervals that exited before this moment were in scope.
    Deleted Count Deleted_Count__c Number (9, 0) Intervals deleted after archive and export.
    Help text: Intervals deleted after archive and export succeeded.
    Interval Count Interval_Count__c Number (9, 0) Intervals in scope when the run started.
    Message Message__c LongTextArea (32768) Result or error from the run.
    Requested By Requested_By__c Lookup (User) Admin who requested the purge.
    Retention Days Retention_Days__c Number (5, 0) Closed intervals older than this many days were purged.
    Help text: Closed intervals older than this many days are archived, exported, and deleted.
    Status Status__c Picklist: Queued, Archiving, Exporting, Deleting, Complete, Failed Progress of the purge job.
    Help text: Updated by the purge job as it archives, exports, and deletes.

    Interval

    The Interval object records one stay of one record in one value of one tracked field, such as a Case in status Working or with owner Priya. It holds the Parent Id, Tracked Field, From and To Values, Entered At and Exited At, and calendar and business minutes; the open interval has no Exited At. Commonly used for time in status and time per owner reports.

    API name: Interval__c

    Field API name Type Description
    Breached At Breached_At__c DateTime When the breach was detected.
    Business Days Business_Days__c Formula (Number) Business minutes as eight-hour business days.
    Help text: Based on an eight-hour business day.
    Business Hours Display Business_Hours_Display__c Formula (Text) Business minutes shown as hours and minutes.
    Help text: Business minutes shown as hours and minutes, for example 34h 15m.
    Business Hours Id Business_Hours_Id__c Text (18) Business hours record used for this interval, kept so minutes can be recomputed.
    Help text: Which business hours were used.
    Business Hours Business_Hours__c Formula (Number) Business minutes as hours.
    Business Minutes To Date Business_Minutes_To_Date__c Number (16, 2) Business minutes so far on an open interval, refreshed by Live values.
    Help text: Refreshed by Live values while open; equals Business Minutes once closed.
    Business Minutes Business_Minutes__c Number (16, 2) Elapsed minutes within business hours between Entered At and Exited At.
    Help text: Set when the interval closes, using the business hours shown in Business Hours Id.
    Calendar Days Calendar_Days__c Formula (Number) Calendar minutes as days.
    Help text: Calendar minutes as 24-hour days.
    Calendar Hours Calendar_Hours__c Formula (Number) Calendar minutes as hours.
    Calendar Minutes To Date Calendar_Minutes_To_Date__c Formula (Number) Minutes since Entered At while open; stored minutes once closed.
    Help text: Calendar minutes to now for an open interval, or the stored minutes when closed.
    Calendar Minutes Calendar_Minutes__c Number (16, 2) Elapsed minutes between Entered At and Exited At.
    Help text: Set when the interval closes.
    Case Origin Case_Origin__c Text (255) Case origin at capture time.
    Case Priority Case_Priority__c Text (255) Case priority at capture time, named so report headers read naturally.
    Help text: Case priority at capture time.
    Case Status At Close Case_Status_At_Close__c Text (255) Status the case closed with, stamped on its intervals when it closes.
    Help text: Status the case closed with.
    Case Type Case_Type__c Text (255) Case type at capture time.
    Case Case__c Lookup (Case) Filled when the tracked object is Case, so Cases with Intervals reports work natively.
    Help text: The Case this interval belongs to.
    Changed By Changed_By__c Lookup (User) Who made the change that started this interval.
    Entered At Entered_At__c DateTime When the record entered this value.
    Exited At Exited_At__c DateTime When the record left this value; empty while the interval is open.
    Help text: Empty while the interval is open.
    From Value From_Value__c Text (255) Value before this interval began.
    Help text: Previous value. Empty on the first interval of a record.
    Goal Minutes Goal_Minutes__c Number (16, 2) Target business minutes copied from the goal at capture time.
    Help text: Target business minutes copied from the goal.
    Goal Goal__c Lookup (Goal__c) Goal that applied to this value when the interval opened.
    Breached Is_Breached__c Checkbox Business minutes to date passed the goal.
    Help text: Set by Live values when business minutes to date pass the goal.
    Open Is_Open__c Formula (Checkbox) True while the record is still in this value.
    Orphaned Is_Orphaned__c Checkbox The tracked record no longer exists; the interval is kept as history.
    Help text: The tracked record was deleted or merged. The interval is kept as history.
    Lead Rating Lead_Rating__c Text (255) Lead rating at capture time.
    Lead Source Lead_Source__c Text (255) Lead source at capture time.
    Lead Lead__c Lookup (Lead) Filled when the tracked object is Lead.
    Help text: The Lead this interval belongs to.
    Opportunity Amount Opportunity_Amount__c Currency (16, 2) Opportunity amount at capture time.
    Opportunity Stage Opportunity_Stage__c Text (255) Opportunity stage at capture time.
    Opportunity Opportunity__c Lookup (Opportunity) Filled when the tracked object is Opportunity.
    Help text: The Opportunity this interval belongs to.
    Owner Id Owner_Id__c Text (18) Owner of the record during this interval, whatever field is tracked.
    Help text: Owner of the record during this interval.
    Owner Name Owner_Name__c Text (255) Owner display name during this interval.
    Owner Type Owner_Type__c Picklist: User, Queue Whether the owner during this interval was a user or a queue.
    Help text: User or Queue.
    Owner User Owner_User__c Lookup (User) Owner as a user lookup, so reports can roll up by role and manager.
    Help text: Set when the owner during this interval is a user.
    Parent Created At Parent_Created_At__c DateTime Created date of the tracked record, for period reporting.
    Help text: Created date of the tracked record.
    Parent Id Parent_Id__c Text (18) Id of the tracked record, stored as text so any object can be tracked.
    Help text: Id of the tracked record.
    Parent Name Parent_Name__c Text (255) Record name or number at capture time, so reports can filter by a readable key.
    Help text: Record name or number at capture time, for example the Case Number.
    Parent Object Parent_Object__c Text (255) API name of the tracked object, the first grouping level in reports.
    Help text: API name of the tracked object, for example Case.
    Parent Record Type Parent_Record_Type__c Text (255) Record type developer name of the tracked record at capture time.
    Help text: Record type of the tracked record at capture time.
    Sequence Sequence__c Number (9, 0) Order of this interval within its record and tracked field.
    Help text: Order of this interval within its record and tracked field, starting at 1.
    Snapshot 1 Snapshot_1__c Text (255) Value of the tracked object's first snapshot field at capture time.
    Help text: Value of the first configured snapshot field at capture time.
    Snapshot 2 Snapshot_2__c Text (255) Value of the tracked object's second snapshot field at capture time.
    Help text: Value of the second configured snapshot field at capture time.
    Snapshot 3 Snapshot_3__c Text (255) Value of the tracked object's third snapshot field at capture time.
    Help text: Value of the third configured snapshot field at capture time.
    Snapshot 4 Snapshot_4__c Text (255) Value of the tracked object's fourth snapshot field at capture time.
    Help text: Value of the fourth configured snapshot field at capture time.
    Snapshot 5 Snapshot_5__c Text (255) Value of the tracked object's fifth snapshot field at capture time.
    Help text: Value of the fifth configured snapshot field at capture time.
    Source Source__c Picklist: Trigger, Flow, Backfill-History, Backfill-Seed, Manual-Repair, Reconcile, Catch-Up How this interval was created.
    Help text: Trigger and Flow are live capture; Backfill and Reconcile are jobs; Manual-Repair comes from the error queue.
    Summarised At Summarised_At__c DateTime When this interval was counted into an Interval Summary row; purge deletes only summarised intervals.
    Help text: Set by the summary job. Purge never deletes an interval without it.
    To Value Id To_Value_Id__c Text (18) Id behind the value for lookup and owner fields.
    Help text: Id of the user, queue, or related record for lookup and owner values.
    To Value Label To_Value_Label__c Text (255) Picklist label at capture time, for readable grouping.
    Help text: Picklist label at capture time.
    To Value To_Value__c Text (255) Value held during this interval: picklist API value, or display name for lookups and owner.
    Help text: Value held during this interval.
    Tracked Field Label Tracked_Field_Label__c Text (255) Label of the tracked field for report headers.
    Help text: Label of the tracked field.
    Tracked Field Tracked_Field__c Text (255) API name of the tracked field; always filter or group by it before grouping by value.
    Help text: API name of the tracked field, for example Status or OwnerId.
